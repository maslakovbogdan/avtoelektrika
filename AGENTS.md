# Иллюстрации каталога

Для предметной иллюстрации ориентируйся на Epec 3724 в `img/catalog/mining/epec-3724.webp`. Покажи блок целиком на прозрачном фоне в ракурсе три четверти, с мягким светом и свободным полем вокруг корпуса. Форму, разъёмы и маркировку бери с изображения конкретной модели.

Владелец также одобрил фотографии оборудования в работе. Референсы — пульт TANA Control System на машине (`img/catalog/mining/tana-tcs.webp`) и терминал Wingman рядом с видом рабочей площадки (`img/catalog/mining/tana-wingman.webp`). Для таких кадров важны резкость и хорошо различимый блок в контексте его применения.

Для экрана вращаемой модели сверяй вид с фотографией включённого прибора. При перерисовке сохраняй рабочий режим, расположение и цвет основных зон, показания и единицы измерения. Сравни результат с референсом в масштабе карточки. У TANA Wingman владелец выбрал исходное изображение дисплея с камерой бункера и схемой машины.
